## 📌 Descripción del Proyecto

Este repositorio contiene los archivos y el código fuente correspondientes al Trabajo Final del curso de Ciencia de Datos. El proyecto se titula **"Predicción de Suscripción Bancaria Mediante Modelos de Aprendizaje Automático"**. 

El objetivo principal es aplicar técnicas de Machine Learning para predecir si un cliente suscribirá o no un depósito a plazo fijo, utilizando el conjunto de datos público *Bank Marketing*. Se realiza un análisis comparativo entre algoritmos (Regresión Logística vs. Random Forest) y se evalúa el impacto predictivo de la variable temporal (`duration`).
